# AegisRx Care Drift Copilot

## Global Innovation Hackathon 2026 - Round 3

### Product Thesis

Detect treatment drift earlier. Explain why. Help clinicians act safely.

### Core Flow

Synthetic FHIR data
-> Temporal feature extraction
-> Deterministic risk engine
-> Risk + uncertainty
-> Evidence / "Why Now?"
-> LLM explanation
-> Clinician action
-> Multilingual check-in

### Clinical Safety Boundary

AegisRx is a decision-support prototype.

It does not:
- diagnose a condition
- establish causality
- change medication
- prescribe treatment
- autonomously contact patients

Generative AI is downstream of the deterministic risk engine and is used for explanation and communication.

### Demonstration Scenarios

1. Possible adverse-effect pathway
2. Routine disruption / forgetfulness
3. Potential access / affordability barrier

### Data

All patient data used in the prototype is synthetic.
